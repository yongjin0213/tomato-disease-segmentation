# Tomato Disease Segmentation

Agriculture tech research on foundation-model-based
instance segmentation of diseased tomato leaves.

## Research pipelines

1. YOLO + SAM 2
2. Ground Truth Bounding Boxes + SAM 2
3. Grounding DINO + SAM 2 (planned)

- Future direction will include application and fine-tuning of VLMs for disease detection

## Infrastructure

- Google Colab: GPU training and inference
- Google Drive: Datasets, checkpoints, and results
- Local Python: Evaluation and visualization
- GitHub: Version control
